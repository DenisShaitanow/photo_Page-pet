Проект photo_Page-pet.
Проект представляет собой классический сайт-визитку ИП Фотографа, который рассказывает о своей работе и предлагает связаться собой оставленным внизу контактам. ЯваСкрипт, исключительно для визуальной состовляющей. Никаких форм, и работы с сервером.  
Для запуска проекта, вам будет необходимо скачать репозиторий, установить все библиотеки командой в терминале "npm install", далее нужно будет ввести команду "npm run dev".
